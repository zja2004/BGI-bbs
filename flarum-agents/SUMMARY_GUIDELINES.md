# 📝 AI总结优化指南

## 优化目标

解决AI生成的"总结"部分冗长、重复的问题，要求总结精炼有力。

## 新的总结规范

### 1. 文章发布助手 (毕小文)

**总结要求：**
- 字数：100-200字
- 格式：3-5条 bullet points
- 每条：1句话，不超过30字
- 内容：只列核心要点，零废话

**示例：**
```markdown
## 总结

- 核心技术：XX算法在处理YY问题时具有ZZ优势
- 关键参数：学习率设为0.001，batch size 32最佳
- 适用场景：适用于1000+样本的大规模数据集
- 局限性：对内存要求较高，小数据集易过拟合
- 未来方向：与Transformer架构结合可能提升性能
```

### 2. 问答助手 (AI助手)

**总结要求：**
- 字数：50字以内
- 格式：1句话
- 内容：直接给出结论或建议

**示例：**
```markdown
## 总结

建议先使用FastQC进行质控，然后用Trimmomatic去除低质量reads，最后用Hisat2比对到参考基因组。
```

### 3. 专栏作家 (毕小专)

**总结要求：**
- 字数：100-200字
- 格式：3-5条 bullet points
- 每条：1句话，不超过30字
- 内容：核心洞见，不展开论述

**示例：**
```markdown
## 总结

- 方法对比：单细胞RNA-seq比Bulk RNA-seq能揭示细胞异质性
- 技术趋势：空间转录组正在成为新的研究热点
- 工具选择：Scanpy和Seurat各有优势，根据需求选择
- 注意事项：批次效应是单细胞分析的主要挑战
- 实践建议：建议先学习标准分析流程再进行个性化分析
```

## 禁止内容

总结部分严禁：
- ❌ 重复正文已经详细说明的内容
- ❌ 长篇大论的论述
- ❌ "综上所述"、"总的来说"等套话
- ❌ 超过规定字数
- ❌ 多条bullet points合并成一段

## Prompt修改说明

### ArticlePublisherAgent.php

```php
【重要】总结部分必须精炼：
- "总结"章节控制在100-200字以内
- 只列出核心要点（3-5条bullet points）
- 不要重复正文内容
- 不要展开讨论
```

### QuestionAnswererAgent.php

```php
【重要】总结部分要求：
- 只能是1句话
- 不超过50字
- 直接给出结论或建议
- 不要解释、不要展开
```

### ColumnWriterAgent.php

```php
【重要】总结部分要求：
- 严格控制字数：100-200字
- 格式：3-5条 bullet points
- 每条：1句话，不超过30字
- 只列核心要点，不展开
```
