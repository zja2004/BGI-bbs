# 【论文解读】CAPSUL：人类蛋白质亚细胞定位的综合基准数据集

## 研究背景

蛋白质亚细胞定位（Subcellular Localization）是细胞生物学中的一个基本问题，因为蛋白质的功能往往与其在细胞内的空间位置密切相关。定位信息对于阐明信号转导、代谢调节和细胞器特异性功能等分子机制至关重要，同时也为药物设计等转化应用提供基础。近年来，数据驱动的AI方法已成为预测蛋白质是否定位于特定亚细胞位置的有力范式，这些方法大幅减少了传统实验技术的时间和成本，同时有望揭示新的生物学模式。

然而，该领域仍面临高质量数据集的严重稀缺。目前AI领域唯一广泛接受的亚细胞定位数据集是DeepLoc，它仅包含蛋白质的氨基酸序列信息。DeepLoc催生了众多基于序列的亚细胞定位模型，这些模型仅根据氨基酸序列推断定位。然而，多项研究表明空间构象在决定亚细胞定位模式中起关键作用。例如，转录因子NF-κB的核定位信号仅在特定结构构象下才暴露，这证明了蛋白质3D结构作为动态调控元件是控制其亚细胞定位的关键。

现有数据集存在以下主要局限：
1. 缺乏显式的蛋白质3D信息——这是结构基方法的关键输入
2. 使用粗粒度的区室分类，将亚细胞区域归为宽泛类别（如不区分核膜和核仁），忽略了不同细胞器的独特定位特征和机制
3. 导致可解释性差，难以发现特定模式和潜在生物学原理

本研究旨在构建一个同时提供综合3D信息和细粒度定位标注的人类蛋白质亚细胞定位数据集，以促进基于结构的方法研究并发现更具体的生物学相关定位模式。

## 核心方法

**1. 数据构建流程**

CAPSUL数据集构建遵循三步流程：

- **步骤1：蛋白质序列和结构数据处理**
  - 从AlphaFold2数据库检索所有预测的人类蛋白质结构（20,504个）
  - 仅保留UniProt中标记为活性的蛋白质（20,401个）
  - 排除AlphaFold2采用滑动窗口策略分段预测的长蛋白（最终20,181个）
  - 提取Cα坐标，使用FoldSeek将3D结构token化为3Di序列

- **步骤2：亚细胞定位标注处理**
  - 从UniProt和Human Protein Atlas (HPA)获取详细定位标注
  - 基于DeepLoc和HPA分类方案，整合为20个细粒度类别
  - 分类标准参照权威教材《Molecular Biology of the Cell》（第7版）并由领域专家验证
  - 提取实验证据级别标注：1=实验验证，2=其他证据，0=无证据标注

- **步骤3：数据合并**
  - 整合蛋白质ID、定位标注、氨基酸序列、序列长度、3Di tokens、Cα坐标等信息

**2. 20个细粒度亚细胞定位类别**

| 类别 | 样本数 | 类别 | 样本数 |
|------|--------|------|--------|
| 细胞核 | 7,590 | 高尔基体 | 1,881 |
| 核膜 | 452 | 细胞膜 | 5,777 |
| 核仁 | 1,641 | 内体 | 687 |
| 核质 | 6,786 | 脂滴 | 94 |
| 细胞质 | 6,613 | 溶酶体/液泡 | 453 |
| 细胞溶胶 | 5,386 | 过氧化物酶体 | 110 |
| 细胞骨架 | 2,119 | 囊泡 | 2,863 |
| 中心体 | 1,000 | 初级纤毛 | 983 |
| 线粒体 | 1,768 | 分泌蛋白 | 2,087 |
| 内质网 | 1,710 | 精子 | 652 |

平均每个蛋白质有2.51个定位标注，实验验证标注占比85.7%。

**3. 基线模型评估**

- **序列基模型**：
  - DeepLoc 2.1（基于ESM-1b）
  - ESM-2 650M（预训练/随机初始化）
  - ESM-C 600M（预训练/微调/随机初始化）

- **结构基模型**：
  - CDConv：连续-离散卷积，结合相对距离和动态半径
  - GearNet-Edge：边感知的图卷积网络
  - FoldSeek：基于预训练结构tokenizer的序列模型
  - Graph Transformer：注意力机制处理图结构
  - Graph Mamba：选择性状态空间模型
  - Graph Diffusion：扩散过程传播信息

- **扩展模型**：
  - CDConv + 对比损失
  - ESM-C + CDConv融合（早期/晚期融合）

**4. 优化策略**

- **重加权策略**：逆频率加权、对数逆频率加权、Focal Loss
- **单标签分类**：为每个亚细胞位置训练独立的二元分类器
- **对比学习**：增强正样本对之间的嵌入相似性

## 主要发现

**1. 预训练对序列基模型的重要性**

- ESM-C 600M（预训练）普遍优于ESM-2 650M，可能归因于ESM-C预训练中使用的广泛数据和计算资源
- ESM-C 600M（随机初始化）表现显著差于预训练版本，证实大规模预训练的重要性
- DeepLoc因忽视细粒度分类，在多标签分类任务中表现较差

**2. 3D结构对亚细胞定位任务至关重要**

- CDConv和GearNet-Edge在大多数情况下优于随机初始化的ESM-C
- 消融研究：将Cα坐标随机采样替换为实际结构导致性能显著下降（CDConv micro F1从0.452降至0.329）
- 结构基模型在样本量小的类别上表现更好，能够识别指示特定细胞器定位的特定结构特征

**3. 类别不平衡是主要挑战**

- 大样本类别（如细胞核）上大多数模型表现较强
- 小样本类别（如脂滴，仅94个样本）预测性能普遍较差，部分类别甚至无法产生正确识别的蛋白质
- 重加权策略显著提升结构基模型在少数类上的表现

**4. 模型性能比较**

主要模型micro F1-score排名：
1. ESM-C 600M (微调): 0.713
2. ESM-C+CDConv晚期融合: 0.710
3. CDConv: 0.632
4. ESM-2 650M (微调): 0.609
5. GearNet-Edge: 0.546
6. Graph Transformer: 0.417

**5. 细粒度分类的优势**

- 细粒度标注使模型能够学习更一致、更具生物学意义的定位模式
- 在特定细胞器上的案例研究可发现具有直观生物学可解释性的定位模式

**6. 生物学可解释性案例：高尔基体**

对高尔基体预测精度达100%的CDConv+Transformer模型进行注意力可视化分析发现：
- 模型一致突出显示相似的α-螺旋空间构象（如MFNG的8-27残基、B3GALT2的24-45残基、GIMAP1的273-292残基）
- 这些发现与先前实验证据高度一致：α-螺旋跨膜结构域（20-30个氨基酸）通过调节跨膜区域静电势梯度和脂质膜锚定效率影响高尔基体定位
- 这证实了模型超越序列相似性的结构模式识别能力

## 讨论与意义

**1. 填补领域空白**

CAPSUL是首个系统构建的具有综合3D信息、细粒度细胞器分类和跨参考定位标注的人类蛋白质亚细胞定位数据集。与现有数据集（DeepLoc、setHARD）相比：

| 特征 | DeepLoc | setHARD | CAPSUL |
|------|---------|---------|--------|
| 序列信息 | ✓ | ✓ | ✓ |
| 结构信息 | ✗ | ✗ | ✓ |
| 聚合分类 | ✓ | ✓ | ✓ |
| 详细分类 | ✗ | ✗ | ✓ |
| 实验标注 | ✗ | ✗ | ✓ |

**2. 验证结构基方法的必要性**

通过随机Cα坐标的消融实验，明确证明了准确3D结构输入对于正确预测的决定性作用。结构基模型在少数类上的优势表明它们能够捕获序列基方法难以识别的特定结构特征。

**3. 处理类别不平衡的策略**

研究探索了重加权和单标签分类策略来缓解类别不平衡和任务冲突的影响。结果显示：
- 重加权显著提升结构基模型在少数类上的精度
- 单标签分类进一步改善了之前表现不佳类别的预测性能
- 这些策略为未来在严重类别不平衡的亚细胞定位任务上的研究提供了实用解决方案

**4. 可解释性发现的价值**

高尔基体案例研究展示了结构基模型的强大可解释性。通过注意力机制发现α-螺旋跨膜结构域是决定性定位模式，这与实验文献中的生物学证据相吻合。这种数据驱动的发现为细胞生物学研究提供了新的假设生成途径。

**5. 局限性与未来方向**

当前局限：
- 仅涵盖人类蛋白质，未包含其他模式生物
- AlphaFold2预测结构虽准确但非实验解析结构
- 某些罕见细胞器的样本量仍然有限

未来研究方向：
- 充分整合不同维度信息（氨基酸序列、Cα坐标、3Di）的对齐或解耦
- 探索3D结构与亚细胞定位之间的因果关系发现
- 将CAPSUL扩展到更多物种和更完整的蛋白质组

**6. 数据质量保障**

CAPSUL通过三重保障确保高质量：
1. 可靠数据源：AlphaFold2（高准确度、强一致性）、UniProt（权威综合注释）、HPA（高分辨率实验验证）
2. 严格验证和过滤：排除分段AlphaFold结构、移除非活性蛋白质
3. 证据级别支持：提供实验验证状态标注以满足不同研究需求

## 精炼总结

- **首个综合3D结构+细粒度标注的亚细胞定位基准**：CAPSUL包含20,181个人类蛋白质，整合AlphaFold2预测结构（Cα坐标+3Di tokens）和20个细粒度亚细胞区室标注（由UniProt和HPA双重验证）

- **3D结构信息的关键作用**：消融实验显示随机Cα坐标导致性能显著下降，证实准确结构输入是正确预测的决定性因素；结构基模型在少数类上表现优于序列基模型

- **细粒度分类的生物学价值**：相比DeepLoc的10个粗类别，20个细粒度类别（如区分核膜/核仁/核质）使模型能够学习更一致、更具生物学意义的定位模式

- **可解释性驱动的生物学发现**：高尔基体案例研究中，模型通过注意力机制识别出α-螺旋跨膜结构域作为决定性定位模式，与实验文献证据高度吻合

- **类别不平衡的实用解决方案**：重加权和单标签分类策略显著提升模型在少数类（如脂滴仅94个样本）上的性能，为严重不平衡的多标签分类任务提供可行策略
