# Spatially Resolved Transcriptomics: Computational Methods and Practical Analysis Guide

## 引言：从Bulk到空间：转录组学的范式转移

过去二十年，单细胞RNA测序（scRNA-seq）技术彻底改变了我们对细胞异质性的理解。然而，传统scRNA-seq在组织解离过程中丢失了宝贵的空间位置信息——细胞在组织中的空间分布往往与其功能状态密切相关。肿瘤微环境、发育过程中的细胞命运决定、神经系统的空间组织等关键生物学问题，都迫切需要空间背景下的转录组信息。

**空间转录组学**（Spatially Resolved Transcriptomics, SRT）应运而生。根据2024年发表在*Nature Methods*的综述文章，的空间转录组学技术已从2016年的单一方法发展为涵盖十余种商业化平台的成熟技术体系（Williams et al., 2024）。10x Genomics的Visium平台、Slide-seq系列、 Stereo-seq等技术相继问世，使得研究者能够在保留组织空间位置信息的同时获取全转录组数据。

然而，技术的快速发展也带来了新的挑战：如何从空间转录组数据中有效提取生物学洞见？本文将深入探讨空间转录组分析的核心计算方法，提供完整的实践指南，并通过真实数据集演示分析流程。

## 技术原理：空间转录组学的计算基础

### 1. 空间转录组数据的多尺度特性

空间转录组数据的核心特征是**多尺度性**（multi-scale）：

| 尺度 | 描述 | 数据形式 |
|------|------|----------|
| 分子尺度 | 基因表达矩阵 | n × g 矩阵（n: spot/cell, g: gene） |
| 组织尺度 | 空间坐标 | n × 2 或 n × 3 坐标矩阵 |
| 邻域尺度 | 空间邻域关系 | 邻接图（k-NN或RNN） |

这种多尺度特性要求分析方法同时考虑**基因表达相似性**和**空间邻近性**，这是与传统单细胞分析的根本区别。

### 2. 空间基因表达检测的统计方法

空间转录组平台（如Visium）的技术原理是通过在组织切片上放置带有spatial barcode的捕获区域（spots），每个spot捕获该位置的总mRNA。关键统计问题是如何从有限的捕获效率中准确检测空间变异性基因（Spatially Variable Genes, SVG）。

**SpatialDE**（Svensson et al., 2018）是首个专门针对空间转录组数据设计的SVG检测方法。其核心思想是将基因表达分解为：

$$y_i = \mu + f_{spatial}(s_i) + \epsilon_i$$

其中 $y_i$ 是位置 $s_i$ 处的基因表达值，$f_{spatial}$ 是空间相关函数，$\epsilon_i$ 是噪声。SpatialDE使用高斯过程（Gaussian Process）建模空间相关性，通过比较模型拟合优度识别显著的空间模式。

**SPARK**（Sun et al., 2020）进一步发展了这一思想，采用广义线性空间模型（Generalized Linear Spatial Model），能够处理计数数据并提供严格的统计显著性检验。SPARK在模拟数据上的SVG检测准确率（AUC）达到0.89，显著优于SpatialDE的0.76（Sun et al., 2020, *Nature Methods*）。

### 3. 空间邻域分析框架

空间转录组分析的另一核心是**邻域效应**——细胞/spot的基因表达受到其空间邻域的显著影响。**Giotto**（Dries et al., 2021）提供了完整的空间邻域分析框架：

- **空间权重矩阵**：基于k近邻（k-NN）或径向邻域（radius-based）构建
- **邻域富集分析**：识别特定细胞类型在空间上的共定位或排斥模式
- **空间通讯分析**：基于配体-受体表达推断细胞间通讯

**Seurat v5**（ Hao et al., 2024）也整合了空间转录组分析功能，通过"Anchor-based"整合方法实现单细胞与空间数据的联合分析。

### 2. 10x Visium数据读取与预处理

```python
import scanpy as sc
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from scipy import sparse

# 读取10x Visium数据
# 假设数据位于 ./data/
adata = sc.read_visium('data/', count_file='filtered_feature_bc_matrix.h5')

# 基本信息
print(f"Spots: {adata.n_obs}")
print(f"Genes: {adata.n_vars}")
print(f"Spatial coordinates shape: {adata.obsm['spatial'].shape}")

# 质控：过滤低质量spot和基因
sc.pp.filter_cells(adata, min_genes=200)
sc.pp.filter_genes(adata, min_cells=3)

# 计算QC指标
adata.var['mt'] = adata.var_names.str.startswith('MT-')
sc.pp.calculate_qc_metrics(adata, qc_vars=['mt'], percent_top=None, log1p=False, inplace=True)

# 过滤线粒体基因占比过高的spot
adata = adata[adata.obs.pct_counts_mt < 20, :]

# 数据标准化
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)

# 识别高变基因
sc.pp.highly_variable_genes(adata, n_top_genes=2000, flavor='seurat_v3')

print(f"After QC: {adata.n_obs} spots, {adata.n_vars} genes")
print(f"Highly variable genes: {adata.var.highly_variable.sum()}")
```

### 3. 空间变异性基因检测

```python
# 方法1: SpatialDE
import spatialde

# 准备SpatialDE输入
counts = adata.X.toarray() if sparse.issparse(adata.X) else adata.X
coords = pd.DataFrame(adata.obsm['spatial'], columns=['x', 'y'])

# 运行SpatialDE
results = spatialde.test.spatial_de_test(coords, counts, adata.var_names)
results = results.sort_values('qval')

# 提取显著SVG (FDR < 0.05)
svg_spatialde = results[results['qval'] < 0.05]['gene'].tolist()
print(f"SVG detected by SpatialDE: {len(svg_spatialde)}")

# 方法2: SPARK (通过pySPARK接口)
# 注意: SPARK需要额外安装
# pip install pySPARK

# 方法3: Scanpy内置的moran's I
sc.pp.pca(adata, n_comps=50)
sc.pp.neighbors(adata)
sc.tl.moran(adata, n_jobs=10)  # 计算Moran'I统计量

# 提取显著空间相关基因
svg_moran = adata.var[adata.var['moranI_pvalue'] < 0.05].index.tolist()
print(f"SVG detected by Moran's I: {len(svg_moran)}")
```

### 4. 空间邻域分析

```python
import squidpy as sq

# 构建空间邻域图
sq.gr.spatial_neighbors(adata, coord_type='grid', n_neighs=6)

# 计算空间自相关（Geary's C）
sq.gr.spatial_autocorr(adata, mode='geary')

# 邻域富集分析
sq.gr.nhood_enrichment(adata, cluster_key='cluster')

# 可视化邻域富集
fig, ax = plt.subplots(1, 1, figsize=(10, 8))
sq.pl.nhood_enrichment(adata, cluster_key='cluster', ax=ax)
plt.tight_layout()
plt.savefig('neighborhood_enrichment.png', dpi=150)
plt.show()

# 空间通讯分析（基于配体-受体）
# 使用CellChat数据库
sq.gr.interaction_matrix(adata, cluster_key='cluster')
sq.pl.interaction_matrix(adata, cluster_key='cluster', figsize=(8, 8))
```

## 案例分析：小鼠脑空间转录组数据实战

### 1. 数据获取

使用10x Genomics官方发布的小鼠脑（Dorsal Pallium）Visium数据集：

```python
# 从10x Genomics网站下载示例数据
import urllib.request
import os

data_dir = './mouse_brain_data/'

# 读取已处理数据（实际分析中可跳过下载步骤）
adata = sc.read_visium('V1_Mouse_Brain_Sagittal_Anterior/')
print(f"Loaded: {adata.n_obs} spots, {adata.n_vars} genes")
```

### 2. 完整分析流程

```python
# ==================== 完整分析流程 ====================

# Step 1: 预处理
sc.pp.filter_cells(adata, min_genes=100)
sc.pp.filter_genes(adata, min_cells=3)
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
sc.pp.highly_variable_genes(adata, n_top_genes=2000)

# Step 2: 降维与聚类
sc.pp.pca(adata, n_comps=50, use_highly_variable=True)
sc.pp.neighbors(adata, n_pcs=50, n_neighbors=15)
sc.tl.leiden(adata, resolution=0.8)
sc.tl.umap(adata)

# Step 3: 空间变异性基因检测
sc.tl.moran(adata, n_jobs=8)
top_svg = adata.var.nlargest(20, 'moranI').index.tolist()

# Step 4: 空间邻域分析
sq.gr.spatial_neighbors(adata, n_neighs=6)
sq.gr.nhood_enrichment(adata, cluster_key='leiden')

# Step 5: 可视化
fig, axes = plt.subplots(2, 3, figsize=(18, 12))

# 5.1 组织切片空间分布
sc.pl.spatial(adata, color='leiden', ax=axes[0, 0], 
              title='Leiden Clusters', size=1.5)

# 5.2 UMAP可视化
sc.pl.umap(adata, color='leiden', ax=axes[0, 1], 
           title='UMAP by Cluster')

# 5.3 Top SVG空间表达
sc.pl.spatial(adata, color=top_svg[:3], ax=axes[0, 2], 
              title='Top SVG Expression', size=1.5, ncols=3)

# 5.4 空间邻域富集热图
sq.pl.nhood_enrichment(adata, cluster_key='leiden', ax=axes[1, 0],
                       title='Neighborhood Enrichment')

# 5.5 特定基因的空间表达模式
gene_of_interest = 'Mbp'  # 髓鞘相关蛋白
sc.pl.spatial(adata, color=[gene_of_interest], ax=axes[1, 1],
              title=f'Spatial Expression: {gene_of_interest}', size=1.5)

# 5.6 细胞类型空间分布密度
sc.pl.spatial(adata, color='leiden', ax=axes[1, 2],
              title='Cluster Spatial Distribution', size=1.5,
              crop_coord=[200, 400, 200, 400])  # 放大特定区域

plt.tight_layout()
plt.savefig('spatial_analysis_results.png', dpi=200, bbox_inches='tight')
plt.show()

# ==================== 性能统计 ====================
print("\n" + "="*50)
print("Analysis Summary")
print("="*50)
print(f"Total spots analyzed: {adata.n_obs}")
print(f"Total genes: {adata.n_vars}")
print(f"Number of clusters: {adata.obs['leiden'].nunique()}")
print(f"Significant SVG (Moran I p<0.05): {(adata.var['moranI_pvalue'] < 0.05).sum()}")
print(f"PC runtime: ~2-3 minutes on 8-core CPU")
print(f"Memory usage: ~4-6 GB")
```

## 讨论：方法比较与适用场景

### 1. 主流空间转录组分析平台对比

| 平台 | 空间分辨率 | 捕获面积 | 通量 | 适用场景 |
|------|------------|----------|------|----------|
| 10x Visium | 55μm (spot) | 6.5mm × 6.5mm | 高 | 整块组织切片 |
| Slide-seq V2 | ~10μm | 3mm × 3mm | 中 | 高分辨率脑区 |
| Stereo-seq | 500nm | cm级 | 高 | 发育生物学 |
| Xenium | 亚细胞 | 多个mm² | 中 | 靶向panel验证 |

### 2. SVG检测方法比较

| 方法 | 统计模型 | 优势 | 局限 |
|------|----------|------|------|
| SpatialDE | 高斯过程 | 速度快，可识别多种空间模式 | 假设正态分布 |
| SPARK | GLM | 处理计数数据，严格统计检验 | 计算较慢 |
| Moran's I | 空间自相关 | 简单快速 | 仅检测全局模式 |
| trendSDE | 混合模型 | 识别局部空间模式 | 参数敏感 |

根据Dries等人（2021）在*Nature Biotechnology*的基准测试，对于10x Visium数据，SPARK在SVG检测的精确度-召回率平衡上表现最佳（F1=0.72），但运行时间是SpatialDE的5-8倍。

### 3. 空间分析方法的选择建议

- **探索性分析**：使用Scanpy + Moran's I，快速获得整体图景
- **严格SVG检测**：使用SPARK或SpatialDE，获得统计显著的基因列表
- **细胞间通讯**：使用Giotto或CellChat（空间扩展版）
- **多模态整合**：使用Seurat v5的anchor-based方法整合scRNA-seq

## 展望：空间转录组学的未来方向

### 1. 技术发展趋势（2024-2025）

**多组学空间整合**：2024年*Cell*杂志报道的Visium HD和CosMx SMI技术已经实现了单细胞级分辨率的空间转录组检测（Chen et al., 2024）。预计2025年将有更多亚细胞分辨率平台商业化。

**AI驱动的分析范式**：深度学习模型如scGPT、GeneBERT正在被改编用于空间转录组数据。2024年发表的**stDEseq**（Spatial Deep Sequencing）框架结合Transformer架构，在SVG检测任务上比传统方法提升15%的准确率。

### 2. 计算生物学前沿问题

- **时空转录组**：整合时间序列与空间信息，追踪细胞命运转变
- **因果推断**：从空间相关性走向因果关系建模
- **可解释AI**：开发针对空间转录组数据的可解释深度学习模型

### 3. 开放资源与生态建设

- **Spatial Atlas Project**：整合人类和小鼠的空间转录组参考图谱
- **SpaGCN**（2024更新）：图神经网络方法整合空间与基因表达信息
- **StereoMap**：国内团队开发的Stereo-seq数据分析套件

## 结语：思考与探索

空间转录组学正在重塑我们对组织微环境的理解方式。本文系统介绍了从数据预处理到空间变异性检测、邻域分析的核心方法，并提供了完整的实践代码。在结束之前，我想提出几个值得深入思考的问题：

1. **分辨率悖论**：更高空间分辨率是否总是带来更好的生物学发现？当spot缩小到单细胞甚至亚细胞级别时，我们如何避免过度解读噪声？

2. **批次效应空间化**：传统的批次效应校正方法（如Harmony、ComBat）主要关注基因表达相似性。如何在保留真实空间模式的同时校正技术批次效应？

3. **从描述到预测**：当前空间转录组分析仍以描述性为主。如何构建可预测的空间模型，模拟扰动（如基因敲除、药物处理）后的空间表达变化？

这些问题指向了空间转录组学计算方法的前沿方向，也欢迎读者在实践中探索与交流。
