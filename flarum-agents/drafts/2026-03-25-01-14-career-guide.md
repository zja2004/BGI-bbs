# 单细胞RNA测序批次效应校正：算法原理、实践指南与性能对比

## 引言

单细胞RNA测序（scRNA-seq）技术已彻底改变了我们理解细胞异质性的方式。然而，当研究涉及多个测序批次、不同技术平台或来自不同实验室的样本时，**批次效应（batch effect）** 成为阻碍数据分析的关键挑战。批次效应会导致相同类型的细胞在降维可视化中分离，严重影响细胞类型注释、差异表达分析和轨迹推断的准确性。

据2023年一项涵盖12种校正方法的系统性基准研究（[Xu et al., Nature Biotechnology 2023](https://www.nature.com/articles/s41587-023-01688-w)），未校正的批次效应可使细胞类型注释准确率下降高达40%。因此，掌握批次效应校正技术是每位生信从业者的核心技能。

本文将深入解析当前主流的四种批次效应校正方法——**Seurat v3 CCA整合**、**Harmony**、**Scanorama**和**Liger**——从算法原理到代码实现，帮助读者建立完整的知识体系并能够独立完成实际数据分析。

## 技术原理

### 批次效应的本质

批次效应并非简单的技术噪声，而是源于实验过程中多种因素的复杂组合：

| 批次效应来源 | 具体表现 |
|-------------|---------|
| 测序平台差异 | 10x Genomics vs. Drop-seq vs. Smart-seq2 |
| 试剂批次变化 | 文库构建试剂、逆转录酶活性差异 |
| 实验室环境 | 温度、湿度、操作人员差异 |
| 测序深度 | 测序饱和度、reads per cell差异 |
| 细胞存活率 | 解离过程中的细胞应激反应 |

### 核心算法解析

#### 1. Seurat v3 CCA整合（Canonical Correlation Analysis）

Seurat v3（[Stuart et al., Cell 2019](https://www.cell.com/cell/fulltext/S0092-8674(19)30504-5)）引入的CCA方法是基于**最大相关变量对齐**的思路：

```
核心步骤：
1. 识别每个批次的高变基因（FindVariableFeatures）
2. 对所有批次进行PCA降维
3. 使用CCA找到批次间的最大相关投影空间
4. 在CCA空间中识别"锚点"细胞对（anchors）
5. 基于锚点进行数据整合与校正
```

**优势**：对技术差异较大的批次（如不同平台）表现稳健
**局限**：计算资源消耗大，对超大规模数据集（>100k细胞）不友好

#### 2. Harmony（基于迭代的软聚类方法）

Harmony（[Korsunsky et al., Nature Methods 2019](https://www.nature.com/articles/s41592-019-0619-0)）采用独特的**迭代软聚类**策略：

```
核心步骤：
1. 初始化：使用PCA嵌入进行k-means聚类
2. 计算每个细胞属于各聚类的概率（φ）
3. 计算批次校正向量：基于加权平均的批次中心偏移
4. 更新细胞嵌入：向聚类中心移动，同时校正批次偏移
5. 迭代直到收敛（默认Δ<1%）
```

**优势**：速度快、内存效率高、支持在线整合新数据
**局限**：对极端批次效应可能过度校正

#### 3. Scanorama（基于互最近邻的批次对齐）

Scanorama（[Hie et al., Nature Biotechnology 2019](https://www.nature.com/articles/s41587-019-0113-7)）的核心思想是**识别批次间的互最近邻（Mutual Nearest Neighbors, MNN）**：

```
核心步骤：
1. 对每个批次独立进行PCA降维
2. 在所有批次对之间识别MNN细胞对
3. 计算MNN对的校正向量（batch correction vector）
4. 使用高斯核平滑校正向量
5. 将校正应用于所有细胞
```

**优势**：对批次间差异的假设最少，适用范围广
**局限**：对批次间无重叠细胞类型时可能失效

#### 4. Liger（iNMF-based整合）

Liger（[Welch et al., Cell 2019](https://www.cell.com/cell/fulltext/S0092-8674(19)30413-1)）使用**交替非负矩阵分解（iNMF）**：

```
核心步骤：
1. 对每个批次分别进行NMF分解：X_k ≈ W_k × H_k
2. 识别批次间共享的因子（跨批次因子）
3. 基于共享因子进行数据对齐
4. 使用 quantile normalization 消除批次差异
```

**优势**：可同时识别批次特异性与共享的细胞程序
**局限**：参数调优复杂，NMF分解耗时

```python
# 创建模拟批次效应数据
def create_simulation_data():
    """创建包含已知细胞类型和批次效应的模拟数据"""
    n_cells_per_batch = 500
    n_genes = 2000
    n_batches = 3
    cell_types = ['T细胞', 'B细胞', '巨噬细胞', '树突状细胞']
    
    adata_list = []
    
    for batch_idx in range(n_batches):
        # 为每个批次生成基础表达矩阵
        base_expr = np.random.randn(n_cells_per_batch, n_genes) * 0.5
        
        # 添加批次特异性偏移（模拟批次效应）
        batch_offset = np.random.randn(1, n_genes) * 0.8
        base_expr += batch_offset
        
        # 为不同细胞类型添加差异表达信号
        for ct_idx, ct in enumerate(cell_types):
            start_idx = ct_idx * (n_cells_per_batch // len(cell_types))
            end_idx = (ct_idx + 1) * (n_cells_per_batch // len(cell_types))
            # 细胞类型特异性基因表达
            type_marker_genes = np.random.choice(n_genes, 50, replace=False)
            base_expr[start_idx:end_idx, type_marker_genes] += 2.0
        
        # 创建AnnData对象
        adata = sc.AnnData(
            X=np.abs(base_expr),  # 确保非负
            obs={
                'cell_type': np.repeat(cell_types, n_cells_per_batch // len(cell_types)),
                'batch': f'Batch_{batch_idx}'
            },
            var={'gene_names': [f'Gene_{i}' for i in range(n_genes)]}
        )
        adata_list.append(adata)
    
    # 合并数据
    adata = sc.concat(adata_list, label='batch', keys=[f'Batch_{i}' for i in range(n_batches)])
    adata.obs_names = [f"Cell_{i}" for i in range(adata.n_obs)]
    
    return adata

# 生成模拟数据
```

```python
# 预处理：过滤、归一化、特征选择
def preprocess_standard(adata):
    """标准scRNA-seq预处理流程"""
    # 保留表达基因数>200的细胞
    sc.pp.filter_cells(adata, min_genes=200)
    # 保留在>10个细胞中表达的基因
    sc.pp.filter_genes(adata, min_cells=10)
    
    # 计算线粒体基因比例（质控指标）
    adata.var['mt'] = adata.var_names.str.startswith('MT-')
    sc.pp.calculate_qc_metrics(adata, qc_vars=['mt'], percent_top=None, log1p=False, inplace=True)
    
    # 保留线粒体基因比例<20%的细胞
    adata = adata[adata.obs.pct_counts_mt < 20, :].copy()
    
    # 总计数归一化
    sc.pp.normalize_total(adata, target_sum=1e4)
    # 对数转换
    sc.pp.log1p(adata)
    
    # 识别高变基因
    sc.pp.highly_variable_genes(
        adata, 
        n_top_genes=1500, 
        batch_key='batch',
        flavor='seurat_v3'
    )
    
    # 仅保留高变基因进行下游分析
    adata = adata[:, adata.var.highly_variable].copy()
    
    # 标准化
    sc.pp.scale(adata, max_value=10)
    
    return adata

adata = preprocess_standard(adata)
print(f"预处理后: {adata.n_obs} 细胞 × {adata.n_genes} 基因")
```

### 四种校正方法实现

```python
# 方法1: Harmony校正
def run_harmony(adata):
    """使用Harmony进行批次效应校正"""
    from harmonypy import run_harmony
    
    # PCA降维
    sc.tl.pca(adata, n_comps=50, use_highly_variable=True)
    
    # Harmony校正
    adata_harmony = adata.copy()
    harmony_out = run_harmony(
        adata_harmony.obsm['X_pca'],
        adata_harmony.obs,
        'batch',
        max_iter_kmeans=10,
        theta=2.0,  # 校正强度参数
        sigma=0.1   # 高斯核带宽
    )
    
    adata_harmony.obsm['X_pca_harmony'] = harmony_out.Z_corr
    return adata_harmony

# 方法2: Scanorama校正
def run_scanorama(adata):
    """使用Scanorama进行批次效应校正"""
    import scanorama
    
    # 按批次分离数据
    batches = adata.obs['batch'].unique()
    adata_list = [adata[adata.obs['batch'] == b].copy() for b in batches]
    
    # 提取表达矩阵
    exprs_list = [ad.X for ad in adata_list]
    
    # Scanorama整合
    corrected, genes = scanorama.correct_scanpy(exprs_list, adata_list, return_dimred=True)
    
    # 合并结果
    adata_scanorama = sc.concat(corrected, label='batch', keys=batches)
    adata_scanorama.obsm['X_scanorama'] = corrected[0].obsm['X_scanorama']
    
    return adata_scanorama

# 方法3: Seurat v3风格整合（使用Scanpy的BBKNN）
def run_bbknn(adata):
    """使用BBKNN进行批次效应校正"""
    import bbknn
    
    # PCA降维
    sc.tl.pca(adata, n_comps=50, use_highly_variable=True)
    
    # BBKNN计算邻居（考虑批次）
    bbknn.bbknn(adata, batch_key='batch', n_pcs=50, trim=50)
    
    # UMAP降维
    sc.tl.umap(adata)
    
    return adata

# 方法4: Liger风格整合（使用Scanpy的mnn_correct）
def run_mnn(adata):
    """使用MNN进行批次效应校正"""
    import scanpy.external as sce
    
    # PCA降维
    sc.tl.pca(adata, n_comps=50, use_highly_variable=True)
    
    # MNN校正
    adata_mnn = adata.copy()
    sce.pp.mnn_correct(
        adata_mnn, 
        batch_key='batch',
        save_raw=False,
        do_concatenate=True
    )
    
    # 重新PCA
    sc.tl.pca(adata_mnn, n_comps=50)
    
    return adata_mnn

print("开始运行各校正方法...")
print("1. Harmony校正...")
adata_harmony = run_harmony(adata)
print("2. Scanorama校正...")
adata_scanorama = run_scanorama(adata)
print("3. BBKNN校正...")
adata_bbknn = run_bbknn(adata.copy())
print("4. MNN校正...")
adata_mnn = run_mnn(adata.copy())
print("所有方法运行完成！")
```

```python
# 计算批次效应校正效果评估指标
from sklearn.metrics import silhouette_score
from sklearn.preprocessing import LabelEncoder

def evaluate_batch_correction(adata, method_name):
    """评估批次效应校正效果"""
    # 使用PCA空间计算silhouette score
    X_pca = adata.obsm['X_pca'][:, :30]
    
    # 批次silhouette（越低越好，表示批次效应被消除）
    le_batch = LabelEncoder()
    batch_labels = le_batch.fit_transform(adata.obs['batch'])
    batch_silhouette = silhouette_score(X_pca, batch_labels)
    
    # 细胞类型silhouette（越高越好，表示细胞类型信息保留）
    le_type = LabelEncoder()
    type_labels = le_type.fit_transform(adata.obs['cell_type'])
    type_silhouette = silhouette_score(X_pca, type_labels)
    
    # kBET检测（批次效应检验）
    kbet_score = compute_kbet(adata, batch_labels)
    
    return {
        'method': method_name,
        'batch_silhouette': batch_silhouette,
        'type_silhouette': type_silhouette,
        'kBET': kbet_score
    }

def compute_kbet(adata, batch_labels, k=50):
    """简化的kBET计算"""
    from sklearn.neighbors import NearestNeighbors
    
    X = adata.obsm['X_pca'][:, :30]
    nbrs = NearestNeighbors(n_neighbors=k+1).fit(X)
    _, indices = nbrs.kneighbors(X)
    
    # 排除自身
    indices = indices[:, 1:]
    
    # 计算邻居中同批次比例
    reject_rates = []
    for i in range(len(X)):
        neighbors = indices[i]
        same_batch = np.mean(batch_labels[neighbors] == batch_labels[i])
        reject_rates.append(1 - same_batch)
    
    return np.mean(reject_rates)

# 评估各方法
results = []
results.append(evaluate_batch_correction(adata, '原始数据'))
results.append(evaluate_batch_correction(adata_harmony, 'Harmony'))
results.append(evaluate_batch_correction(adata_bbknn, 'BBKNN'))

# 结果汇总
results_df = pd.DataFrame(results)

print("=" * 60)

print("- kBET: 越低越好（表示批次分布均匀）")
```
