# DNA语言模型在调控基因组学中的应用：从原理到实践

## 引言：基因组序列的"语义理解"困境

基因组学研究的根本挑战之一在于理解DNA序列的功能意义。传统方法依赖序列比对和 motif 识别，但这些方法难以捕捉序列的上下文依赖性和长程相互作用。随着大规模基因组数据的积累和深度学习技术的成熟，**DNA语言模型（DNA Language Models, DLMs）** 应运而生，为基因组序列的"语义理解"提供了新的范式。

2023-2024年，DNA语言模型领域取得了突破性进展。Meta AI发布的**Nucleotide Transformer**（Dinan et al., 2024）在人类基因组上预训练后，在多种下游任务上显著优于传统方法。**DNABERT-2**（Zhou et al., 2023）则引入了更高效的tokenization策略，在推理速度上提升了数倍。这些进展使得从原始DNA序列直接预测基因表达、染色质状态和变异效应成为可能。

本文将深入探讨DNA语言模型的技术原理，提供完整的实践代码，并通过真实数据集展示其在调控基因组学中的应用。

## 技术原理：DNA语言模型的核心架构

### 1. 从NLP到基因组学的范式迁移

DNA语言模型的核心思想是将DNA序列视为一种"语言"，借鉴自然语言处理（NLP）的预训练-微调范式。与自然语言类似，基因组序列具有以下特征：

- **序列相关性**：碱基的排列顺序决定功能
- **上下文依赖**：同一motif在不同位置可能具有不同功能
- **长程依赖**：增强子与启动子的相互作用可跨越数十kb

### 2. 模型架构：Transformer的适配

DNA语言模型通常采用Transformer架构，但对tokenization进行了特殊适配：

| 模型 | Tokenization策略 | 上下文长度 | 参数量 |
|------|------------------|------------|--------|
| DNABERT-1 | k-mer (k=3,4,5,6) | 512 | 86M |
| DNABERT-2 | BPE | 4096 | 117M |
| Nucleotide Transformer | k-mer (k=3) | 4096 | 250M/500M |

**关键创新**：Nucleotide Transformer采用**multi-species预训练**策略，在人类、小鼠、斑马鱼等多种物种的基因组上联合训练，使模型学习到跨物种的保守序列模式。

### 3. 预训练任务设计

DNA语言模型的预训练通常采用以下任务：

1. **掩码语言建模（MLM）**：随机掩码15%的token，预测被掩码的碱基
2. **序列生成**：给定前缀，预测后续序列
3. **对比学习**：使相似功能的序列在嵌入空间中接近

### 4. 下游任务适配

预训练模型通过以下方式适配下游任务：

```
预训练模型 → [CLS] token / 平均池化 → 任务头 → 输出
```

对于回归任务（如预测基因表达量），使用线性输出层；对于分类任务（如预测染色质状态），使用softmax输出层。

### 2. 模型加载与基础使用

```python
import torch
from transformers import AutoTokenizer, AutoModel
import numpy as np

# 加载DNABERT-2 (以huggingface格式)
model_name = "zhihan1996/dnabert-2"
tokenizer = AutoTokenizer.from_pretrained(model_name, trust_remote_code=True)
model = AutoModel.from_pretrained(model_name, trust_remote_code=True)

model.eval()
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = model.to(device)

def get_sequence_embedding(sequence):
    """获取DNA序列的嵌入向量"""
    # Tokenize
    inputs = tokenizer(
        sequence, 
        return_tensors="pt", 
        padding=True, 
        truncation=True,
        max_length=4096
    ).to(device)
    
    # 前向传播
    with torch.no_grad():
        outputs = model(**inputs)
    
    # 使用[CLS] token的输出作为序列表示
    embedding = outputs.last_hidden_state[:, 0, :].cpu().numpy()
    return embedding

# 测试
test_seq = "ATGCGATCGATCGATCGATCGATCGATCGATCG"
embedding = get_sequence_embedding(test_seq)
print(f"嵌入维度: {embedding.shape}")  # (1, 768)
```

### 3. 批量处理基因组区域

```python
import pybedtools
import pandas as pd

def extract_sequence(bed_file, genome, output_fasta):
    """从BED文件提取FASTA序列"""
    bed = pybedtools.BedTool(bed_file)
    fasta = bed.sequence(fi=genome, fo=output_fasta, name=True)
    return output_fasta

def batch_embed(sequences, batch_size=32):
    """批量计算序列嵌入"""
    embeddings = []
    
    for i in range(0, len(sequences), batch_size):
        batch = sequences[i:i+batch_size]
        
        # Tokenize batch
        inputs = tokenizer(
            batch,
            return_tensors="pt",
            padding=True,
            truncation=True,
            max_length=4096
        ).to(device)
        
        with torch.no_grad():
            outputs = model(**inputs)
        
        # 提取[CLS] token
        batch_emb = outputs.last_hidden_state[:, 0, :].cpu().numpy()
        embeddings.append(batch_emb)
        
        if (i // batch_size) % 10 == 0:
            print(f"处理进度: {i+len(batch)}/{len(sequences)}")
    
    return np.vstack(embeddings)

# 性能测试
import time
test_seqs = ["ATGC" * 1000 for _ in range(100)]

start = time.time()
embeddings = batch_embed(test_seqs, batch_size=16)
elapsed = time.time() - start

print(f"处理100条序列耗时: {elapsed:.2f}秒")
print(f"平均每条序列: {elapsed/100*1000:.2f}毫秒")
print(f"内存占用: {torch.cuda.memory_allocated()/1024**2:.2f} MB" if torch.cuda.is_available() else "CPU模式")
```

## 案例分析：启动子活性预测

### 1. 数据集准备

我们使用**EPDnew**（人类启动子数据库）和随机基因组背景作为正负样本：

```python
import requests
import gzip
import os

def download_epd():
    """下载人类启动子数据"""
    url = "https://epd.epfl.ch/EPDdownload/EPDnew_organism_human/hg38/EPDnew_hg38_1_200-250.bed.gz"
    
    if not os.path.exists("epd_hg38.bed.gz"):
        print("下载启动子数据...")
        r = requests.get(url)
        with open("epd_hg38.bed.gz", "wb") as f:
            f.write(r.content)
    
    # 解压
    with gzip.open("epd_hg38.bed.gz", "rt") as f:
        df = pd.read_csv(f, sep="\t", header=None)
    
    # 提取启动子上游2kb区域
    df = df.iloc[:, [0, 1, 2, 5]].copy()
    df.columns = ["chrom", "start", "end", "strand"]
    df["start"] = df.apply(lambda x: x["end"]-2000 if x["strand"]=="+" else x["start"], axis=1)
    df["end"] = df.apply(lambda x: x["end"] if x["strand"]=="+" else x["start"]+2000, axis=1)
    
    return df[["chrom", "start", "end"]]

# 生成负样本（随机基因组区域）
def generate_negative_samples(positive_df, n_neg, chrom_sizes):
    """生成随机负样本"""
    negative = []
    chroms = list(chrom_sizes.keys())
    
    for _ in range(n_neg):
        chrom = np.random.choice(chroms)
        chrom_len = chrom_sizes[chrom]
        
        start = np.random.randint(0, chrom_len - 2000)
        end = start + 2000
        
        negative.append([chrom, start, end])
    
    return pd.DataFrame(negative, columns=["chrom", "start", "end"])

# 简化版本：使用模拟数据
np.random.seed(42)
n_samples = 2000

# 正样本：模拟启动子序列（GC富集）
positive_seqs = []
for _ in range(n_samples):
    seq = ""
    for i in range(2000):
        r = np.random.random()
        if r < 0.3:
            seq += "G"
        elif r < 0.6:
            seq += "C"
        elif r < 0.8:
            seq += "A"
        else:
            seq += "T"
    positive_seqs.append(seq)

# 负样本：随机序列
negative_seqs = []
for _ in range(n_samples):
    seq = "".join(np.random.choice(["A", "T", "G", "C"], size=2000))
    negative_seqs.append(seq)

# 合并
all_seqs = positive_seqs + negative_seqs
labels = [1] * n_samples + [0] * n_samples

print(f"数据集大小: {len(all_seqs)}")
print(f"正样本数: {sum(labels)}, 负样本数: {len(labels)-sum(labels)}")
```

### 2. 模型微调

```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score, accuracy_score
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

# 划分数据集
X_train, X_test, y_train, y_test = train_test_split(
    all_seqs, labels, test_size=0.2, random_state=42, stratify=labels
)

print("计算训练集嵌入...")
X_train_emb = batch_embed(X_train, batch_size=32)
print("计算测试集嵌入...")
X_test_emb = batch_embed(X_test, batch_size=32)

# 方法1：直接使用嵌入 + 传统ML分类器
print("\n=== 方法1: 逻辑回归 ===")
clf = LogisticRegression(max_iter=1000, C=1.0)
clf.fit(X_train_emb, y_train)

y_pred_proba = clf.predict_proba(X_test_emb)[:, 1]
y_pred = clf.predict(X_test_emb)

auc = roc_auc_score(y_test, y_pred_proba)
acc = accuracy_score(y_test, y_pred)
print(f"AUC: {auc:.4f}")
print(f"Accuracy: {acc:.4f}")

# 方法2：微调Transformer（更精细的适配）
print("\n=== 方法2: 微调Transformer ===")

class DNAPromoterClassifier(nn.Module):
    def __init__(self, pretrained_model, hidden_dim=256, num_classes=2):
        super().__init__()
        self.encoder = pretrained_model
        self.classifier = nn.Sequential(
            nn.Linear(768, hidden_dim),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(hidden_dim, num_classes)
        )
    
    def forward(self, input_ids, attention_mask):
        outputs = self.encoder(input_ids=input_ids, attention_mask=attention_mask)
        cls_output = outputs.last_hidden_state[:, 0, :]
        return self.classifier(cls_output)

# 冻结编码器参数（可选：解冻部分层）
for param in model.parameters():
    param.requires_grad = False

# 解冻最后2层Transformer
for layer in model.encoder.layers[-2:]:
    for param in layer.parameters():
        param.requires_grad = True

# 准备数据
train_inputs = tokenizer(X_train, return_tensors="pt", padding=True, truncation=True, max_length=2048)
test_inputs = tokenizer(X_test, return_tensors="pt", padding=True, truncation=True, max_length=2048)

train_dataset = TensorDataset(
    train_inputs["input_ids"],
    train_inputs["attention_mask"],
    torch.tensor(y_train)
)
train_loader = DataLoader(train_dataset, batch_size=16, shuffle=True)

# 训练
classifier = DNAPromoterClassifier(model).to(device)
optimizer = torch.optim.AdamW(filter(lambda p: p.requires_grad, classifier.parameters()), lr=1e-4)
criterion = nn.CrossEntropyLoss()

classifier.train()
for epoch in range(3):
    total_loss = 0
    for batch in train_loader:
        input_ids, attention_mask, labels = [b.to(device) for b in batch]
        
        optimizer.zero_grad()
        outputs = classifier(input_ids, attention_mask)
        loss = criterion(outputs, labels)
        
        loss.backward()
        optimizer.step()
        
        total_loss += loss.item()
    
    print(f"Epoch {epoch+1}, Loss: {total_loss/len(train_loader):.4f}")

# 评估
classifier.eval()
with torch.no_grad():
    test_outputs = classifier(test_inputs["input_ids"].to(device), test_inputs["attention_mask"].to(device))
    test_proba = torch.softmax(test_outputs, dim=1)[:, 1].cpu().numpy()

auc_finetune = roc_auc_score(y_test, test_proba)
print(f"\n微调后AUC: {auc_finetune:.4f}")
```

### 4. 变异效应预测

DNA语言模型的一个重要应用是预测遗传变异的功能效应：

```python
def predict_variant_effect(ref_seq, alt_seq, position):
    """预测变异的功能效应"""
    # 提取变异上下文（上下游各500bp）
    start = max(0, position - 500)
    end = min(len(ref_seq), position + 501)
    
    ref_context = ref_seq[start:end]
    alt_context = alt_seq[start:end]
    
    # 替换中心碱基
    ref_center = ref_context[:500] + alt_seq[position] + ref_context[501:]
    alt_center = alt_context[:500] + alt_seq[position] + alt_context[501:]
    
    # 计算嵌入
    ref_emb = get_sequence_embedding(ref_center)
    alt_emb = get_sequence_embedding(alt_center)
    
    # 计算差异（可能表示功能影响）
    diff = np.abs(ref_emb - alt_emb)
    
    return {
        "ref_embedding": ref_emb,
        "alt_embedding": alt_emb,
        "difference": diff,
        "effect_score": np.mean(diff)
    }

# 示例
ref_sequence = "ATGC" * 500
alt_sequence = "ATGC" * 499 + "A" + "ATGC"
result = predict_variant_effect(ref_sequence, alt_sequence, 1000)
print(f"变异效应分数: {result['effect_score']:.6f}")
```

## 讨论：优势与局限性

### 1. DNA语言模型的优势

- **端到端学习**：直接从原始序列学习，无需人工设计特征
- **上下文感知**：捕捉长程依赖关系，理解序列的全局语境
- **迁移学习**：预训练模型可快速适配多种下游任务
- **发现新模式**：可识别传统方法难以发现的序列特征

### 2. 当前局限性

| 局限性 | 说明 | 可能的解决方案 |
|--------|------|----------------|
| 序列长度限制 | Transformer的O(n²)复杂度限制上下文长度 | 稀疏注意力、层次化建模 |
| 训练数据偏差 | 预训练数据偏向特定物种或区域 | 多物种、多组织联合训练 |
| 可解释性 | 嵌入空间难以直接解释 | 注意力可视化、probing分析 |
| 计算资源 | 大模型需要GPU资源 | 模型蒸馏、量化 |

### 3. 与传统方法的比较

| 特征 | 传统方法 (k-mer/SVM) | DNA语言模型 |
|------|---------------------|-------------|
| 特征工程 | 人工设计 | 自动学习 |
| 上下文建模 | 有限 | 长程依赖 |
| 训练数据需求 | 中等 | 大规模预训练 |
| 推理速度 | 快 | 较慢 |
| 可解释性 | 高 | 低 |

### 4. 适用场景

DNA语言模型特别适用于：
- 启动子/增强子活性预测
- 染色质状态分类
- 非编码区变异功能注释
- 基因表达预测
- 跨物种功能保守性分析
