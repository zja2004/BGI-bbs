# 图神经网络在单细胞多组学整合中的应用：技术原理与实践指南

## 引言：单细胞多组学整合的挑战

单细胞测序技术的快速发展使得研究者能够在单细胞分辨率下同时获取多种模态的分子信息——转录组、染色质可及性、蛋白质表达等。然而，如何有效整合这些异构数据、揭示细胞类型特异性的分子调控机制，仍是当前生物信息学领域的核心挑战之一。

传统的整合方法主要基于线性变换或矩阵分解，如典型相关分析（CCA）和互信息最大化（MINT），但这些方法难以捕捉细胞间复杂的非线性关系和图结构特征。近年来，**图神经网络（Graph Neural Networks, GNNs）**凭借其强大的图结构建模能力，成为单细胞多组学整合的前沿技术方向。

本文将深入探讨GNN在单细胞多组学整合中的技术原理，提供完整的实践代码，并通过真实数据集展示其分析流程与性能表现。

## 技术原理：图神经网络的核心机制

### 2.1 从单细胞数据到图结构

将单细胞多组学数据转化为图结构是应用GNN的前提。典型的图构建策略包括：

| 构建方法 | 描述 | 适用场景 |
|---------|------|---------|
| **K近邻图（KNN）** | 基于相似性度量连接K个最近邻细胞 | 通用场景，计算效率高 |
| **共享邻域图** | 基于共同邻居数量加权边权重 | 多组学数据整合 |
| **空间邻域图** | 基于细胞空间位置连接 | 空间转录组数据 |
| **基因调控网络图** | 基于TF-target关系构建 | 调控机制研究 |

对于多组学整合，通常采用**跨模态链接策略**：将不同组学数据映射到统一的图结构上，通过图卷积操作实现信息传递。

### 2.2 图卷积神经网络架构

图卷积层是GNN的核心组件。假设输入节点特征为 $X \in \mathbb{R}^{N \times d}$，邻接矩阵为 $A \in \mathbb{R}^{N \times N}$，则单层图卷积可表示为：

$$H^{(l+1)} = \sigma\left(\tilde{D}^{-1/2}\tilde{A}\tilde{D}^{-1/2} H^{(l)} W^{(l)}\right)$$

其中 $\tilde{A} = A + I$（加入自环），$\tilde{D}$ 为度矩阵，$W^{(l)}$ 为可学习权重矩阵，$\sigma$ 为激活函数。

**注意力机制图神经网络（GAT）**进一步引入注意力权重：

$$h_i' = \sigma\left(\sum_{j \in \mathcal{N}_i} \alpha_{ij} \mathbf{W} h_j\right)$$

$$\alpha_{ij} = \frac{\exp(\text{LeakyReLU}(\mathbf{a}^T[\mathbf{W}h_i || \mathbf{W}h_j]))}{\sum_{k \in \mathcal{N}_i} \exp(\text{LeakyReLU}(\mathbf{a}^T[\mathbf{W}h_i || \mathbf{W}h_j]))}$$

注意力机制使模型能够自适应地学习不同邻居节点的重要性，这对于整合异构的多组学数据尤为重要。

### 2.3 多组学整合策略

GNN实现多组学整合主要有三种范式：

1. **早期融合（Early Fusion）**：将不同组学的特征向量拼接后输入GNN
2. **晚期融合（Late Fusion）**：各组学分别构建图并进行图卷积，最后融合表示
3. **注意力融合（Attention-based Fusion）**：通过跨模态注意力机制动态融合不同组学的信息

### 3.2 完整代码实现

以下代码实现基于GAT的单细胞多组学整合流程：

```python
import numpy as np
import pandas as pd
import scanpy as sc
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch_geometric.nn import GATConv, global_mean_pool
from torch_geometric.data import Data
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import kneighbors_graph
import warnings
warnings.filterwarnings('ignore')

# ============================================
# 1. 数据加载与预处理
# ============================================
def load_and_preprocess(rna_path, atac_path):
    """加载RNA和ATAC数据"""
    adata_rna = sc.read_h5ad(rna_path)
    adata_atac = sc.read_h5ad(atac_path)
    
    # 寻找共同细胞
    common_cells = adata_rna.obs_names.intersection(adata_atac.obs_names)
    adata_rna = adata_rna[common_cells]
    adata_atac = adata_atac[common_cells]
    
    # 特征选择：保留高变基因/峰
    sc.pp.highly_variable_genes(adata_rna, n_top_genes=2000)
    sc.pp.highly_variable_features(adata_atac, n_top_features=2000)
    
    return adata_rna, adata_atac

# ============================================
# 2. 图结构构建
# ============================================
def build_knn_graph(adata, n_neighbors=15):
    """基于表达相似性构建KNN图"""
    X = adata.X.toarray() if hasattr(adata.X, 'toarray') else adata.X
    X = StandardScaler().fit_transform(X)
    
    # 构建K近邻图
    adj = kneighbors_graph(X, n_neighbors, mode='connectivity', include_self=False)
    adj = adj.toarray()
    
    # 转换为边索引
    edge_index = np.array(adj.nonzero())
    
    return torch.tensor(edge_index, dtype=torch.long), adj

# ============================================
# 3. GAT模型定义
# ============================================
class MultiOmicsGAT(nn.Module):
    def __init__(self, rna_dim, atac_dim, hidden_dim=128, heads=4, dropout=0.2):
        super(MultiOmicsGAT, self).__init__()
        
        # 模态特定编码器
        self.rna_encoder = nn.Linear(rna_dim, hidden_dim)
        self.atac_encoder = nn.Linear(atac_dim, hidden_dim)
        
        # 图注意力层
        self.gat1 = GATConv(hidden_dim * 2, hidden_dim, heads=heads, dropout=dropout)
        self.gat2 = GATConv(hidden_dim * heads, hidden_dim, heads=heads, dropout=dropout)
        self.gat3 = GATConv(hidden_dim * heads, hidden_dim, heads=1, concat=False, dropout=dropout)
        
        # 分类头
        self.classifier = nn.Sequential(
            nn.Linear(hidden_dim, 64),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(64, 32)
        )
        
    def forward(self, rna_x, atac_x, edge_index):
        # 模态编码
        rna_emb = F.elu(self.rna_encoder(rna_x))
        atac_emb = F.elu(self.atac_encoder(atac_x))
        
        # 特征拼接（早期融合策略）
        x = torch.cat([rna_emb, atac_emb], dim=1)
        
        # 图注意力卷积
        x = F.elu(self.gat1(x, edge_index))
        x = F.elu(self.gat2(x, edge_index))
        x = self.gat3(x, edge_index)
        
        # 嵌入输出
        embeddings = x
        predictions = self.classifier(x)
        
        return embeddings, predictions

# ============================================
# 4. 训练流程
# ============================================
def train_model(adata_rna, adata_atac, labels, epochs=300, lr=0.001):
    # 准备特征
    rna_features = adata_rna.X.toarray() if hasattr(adata_rna.X, 'toarray') else adata_rna.X
    atac_features = adata_atac.X.toarray() if hasattr(adata_atac.X, 'toarray') else adata_atac.X
    
    # 构建图
    edge_index, adj = build_knn_graph(adata_rna, n_neighbors=15)
    
    # 转换为张量
    rna_x = torch.tensor(rna_features, dtype=torch.float32)
    atac_x = torch.tensor(atac_features, dtype=torch.float32)
    y = torch.tensor(labels, dtype=torch.long)
    
    # 初始化模型
    model = MultiOmicsGAT(
        rna_dim=rna_features.shape[1],
        atac_dim=atac_features.shape[1],
        hidden_dim=128,
        heads=4
    )
    
    optimizer = torch.optim.Adam(model.parameters(), lr=lr)
    criterion = nn.CrossEntropyLoss()
    
    # 训练循环
    model.train()
    for epoch in range(epochs):
        optimizer.zero_grad()
        embeddings, predictions = model(rna_x, atac_x, edge_index)
        
        # 聚类任务：使用K-means伪标签或真实标签
        loss = criterion(predictions, y)
        
        loss.backward()
        optimizer.step()
        
        if (epoch + 1) % 50 == 0:
            print(f"Epoch {epoch+1}/{epochs}, Loss: {loss.item():.4f}")
    
    # 推理
    model.eval()
    with torch.no_grad():
        final_embeddings, _ = model(rna_x, atac_x, edge_index)
    
    return model, final_embeddings.numpy()

# ============================================
# 5. 评估指标计算
# ============================================
def evaluate_integration(embeddings, labels, batch_labels=None):
    """计算整合质量指标"""
    from sklearn.metrics import silhouette_score, adjusted_rand_score, normalized_mutual_info_score
    from sklearn.cluster import KMeans
    
    # 聚类评估
    k = len(np.unique(labels))
    kmeans = KMeans(n_clusters=k, random_state=42)
    pred_labels = kmeans.fit_predict(embeddings)
    
    ari = adjusted_rand_score(labels, pred_labels)
    nmi = normalized_mutual_info_score(labels, pred_labels)
    asw = silhouette_score(embeddings, labels)
    
    print(f"ARI: {ari:.4f}")
    print(f"NMI: {nmi:.4f}")
    print(f"ASW: {asw:.4f}")
    
    return {'ARI': ari, 'NMI': nmi, 'ASW': asw}

# ============================================
# 主函数
# ============================================
if __name__ == "__main__":
    # 示例：使用PBMC多组学数据
    # adata_rna, adata_atac = load_and_preprocess("pbmc_rna.h5ad", "pbmc_atac.h5ad")
    
    # 模拟数据演示
    np.random.seed(42)
    n_cells = 1000
    n_genes = 2000
    n_peaks = 2000
    
    # 生成模拟数据
    X_rna = np.random.randn(n_cells, n_genes)
    X_atac = np.random.randn(n_cells, n_peaks)
    labels = np.random.randint(0, 5, n_cells)  # 5个细胞类型
    
    # 创建AnnData对象
    adata_rna = sc.AnnData(X=X_rna)
    adata_atac = sc.AnnData(X=X_atac)
    
    # 训练模型
    print("开始训练GAT模型...")
    model, embeddings = train_model(adata_rna, adata_atac, labels, epochs=100)
    
    # 评估
    print("\n整合评估结果:")
    metrics = evaluate_integration(embeddings, labels)
```

## 讨论：方法论分析与适用场景

### 5.1 优势分析

1. **非线性建模能力**：GNN能够捕捉细胞间复杂的非线性关系，这是线性方法（如CCA）无法实现的
2. **图结构利用**：通过注意力机制自适应学习细胞间关系权重，避免了固定距离度量的局限性
3. **可扩展性**：图稀疏操作使得GNN能够处理大规模单细胞数据集（>100,000细胞）
4. **多模态融合灵活**：支持早期、晚期和注意力融合等多种策略

### 5.2 局限性

1. **超参数敏感**：邻居数、注意力头数、隐藏层维度等参数对结果影响显著
2. **图构建质量依赖**：KNN图的构建质量直接决定整合效果
3. **可解释性挑战**：深度黑箱模型的生物学可解释性仍有待提升
4. **计算资源需求**：相比传统方法需要更多GPU资源

### 5.3 与其他方法的对比

| 特性 | GNN方法 | 线性方法(CCA/MINT) | 深度生成模型(scVI) | 基于流形方法(UMAP) |
|------|---------|-------------------|-------------------|-------------------|
| 非线性建模 | ✓ | ✗ | ✓ | ✓ |
| 图结构利用 | ✓ | ✗ | ✗ | ✓ |
| 可解释性 | 低 | 高 | 低 | 中 |
| 计算效率 | 中 | 高 | 低 | 高 |
| 多组学兼容性 | 高 | 中 | 高 | 中 |

## 展望：未来发展方向

### 6.1 空间多组学整合

随着空间转录组和空间ATAC-seq技术的发展，如何将空间邻域信息融入GNN框架是重要方向。**SpatialGNN**等新型架构正在被开发用于处理空间多模态数据。

### 6.2 预训练大模型

类似于自然语言处理中的BERT和GPT，**单细胞基础模型（Foundation Models）**正在兴起。基于大规模单细胞数据预训练的GNN模型有望实现"零样本"多组学整合。

### 6.3 因果推断与GNN结合

将因果推断框架与GNN结合，能够更准确地识别细胞类型特异性的基因调控因果关系，这对于理解疾病机制具有重要价值。

开发基于Web的交互式GNN分析平台，使生物学家能够在不需要编程的情况下进行单细胞多组学整合分析。
