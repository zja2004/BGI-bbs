# 【论文解读】强化学习引导的生成式蛋白质语言模型实现高度多样化AAV衣壳的从头设计

## 研究背景

腺相关病毒（Adeno-Associated Viral, AAV）载体是基因治疗中最广泛使用的治疗性货物递送平台之一。其广泛的临床评估、持续的转基因表达以及衣壳和基因组工程提供的设计灵活性，推动了其向新的治疗适应症不断扩展。第一代AAV载体取得了重大临床成功，包括获批上市的Luxturna®和Zolgensma®等产品。然而，累积的临床经验揭示了下一代载体的需求：降低免疫原性、提高转导效率或降低器官毒性。

蛋白质工程面临的核心挑战是可能的序列空间相对于可行实验筛选规模的巨大差异。即使对于相对充分表征的蛋白质，也只能实验评估可能序列变体的无穷小比例。因此，能够提出新颖且功能合理的蛋白质序列的计算方法对于指导实验工作变得越来越重要。

近年来，机器学习引导的蛋白质设计已成为导航序列空间和加速功能性AAV变体发现的强大策略。生成式人工智能（AI）通过学习复杂生物序列的潜在分布并使用这种学习表示产生新变体，为蛋白质设计提供了特别有前景的方法。在AAV生物工程背景下，大多数生成研究依赖于变分自编码器（VAE），但VAE生成的序列往往强烈偏向训练数据，且容易出现潜在空间崩溃，限制了探索远离已知序列的序列设计空间区域的能力。

本研究旨在开发一种基于蛋白质语言模型（PLM）和强化学习的生成式设计框架，生成既高度新颖又保持功能可行性的AAV衣壳。

## 核心方法

本研究提出了一个三阶段的生成式设计框架：

**1. 基线：预训练ProGen模型**

使用ProGen2-small（3.6亿参数）作为基础模型，该模型在数亿个多样化蛋白质序列上预训练。直接采样产生100%独特序列，但所有序列被分类为不可行（non-viable），说明通用PLM缺乏功能指导。

**2. 监督微调（Fine-tuning）**

使用Bryant等人（2021）的AAV2衣壳可行性数据集进行微调，仅使用可行（阳性）序列训练。损失函数仅计算可变区域（位置561-588）的交叉熵，前缀（1-560）和后缀（最后147个位置）被掩码以防止对不变位置的过拟合：
```
L = -Σᵢ maskᵢ · log P(xᵢ | x₁, ..., xᵢ₋₁)
```

微调后的模型在温度0.8和1.2下各生成10万序列，82%（t=0.8）和73%（t=1.2）为独特序列。其中98%（t=0.8）和91%（t=1.2）被分类为可行。

**3. 强化学习（RL）引导生成**

在微调模型基础上，采用双分支奖励结构的强化学习框架：

- **多样性分支**：使用冻结的ESM2模型生成序列嵌入，通过余弦距离计算相对于参考序列（AAV2野生型）的新颖性分数。新颖性分数表示为微调生成集中观察到的距离分布的百分位数，超过最大值时通过幂律缩放进行额外奖励。

- **功能分支**：使用ProtBERT+分类头评估预测可行性，该分类器在AAV2可行性实验数据上专门微调。

- **奖励函数**：
```
R = I(p_viable ≥ τ) · (p_viable)^α · (novelty)^β · (novelty/novelty_max)^γ
```

其中I为指示函数，τ为可行性阈值，α、β、γ控制各组件的相对影响。

- **策略更新**：使用KL正则化目标相对于冻结参考模型进行策略更新，仅保留每批中top-q的序列，负优势被裁剪为零。训练目标最小化加权token级负对数似然与KL和熵正则化的组合。

**4. 候选选择策略**

对于RL生成的序列，由于预测可行性普遍较高（99-100%），需要额外的选择标准。研究提出基于生物物理属性的网格采样策略：

- **极性**：使用Wimley-White指数计算，考虑疏水性和亲水性贡献
- **电荷**：计算阳离子（R、K）和阴离子（D、E）残基数量，得到净电荷

将2D空间（总极性 vs 总电荷）划分为9或25个区域，在每个区域内选择新颖性分数最高的序列作为候选。限制边界为阳性序列分布的中间90%，排除极端值。

## 主要发现

**1. 不同策略的序列特性**

| 策略 | 独特序列数(t=0.8) | 独特序列数(t=1.2) | 可行比例 |
|------|-------------------|-------------------|----------|
| 预训练ProGen | 100,000 | 100,000 | 0% |
| (+)FT ProGen | 82,031 | 72,509 | 98% / 91% |
| (+)FT & RL ProGen | 330 | 9,403 | 100% / 99% |

预训练模型生成100%独特序列但全部不可行；微调模型生成大量独特可行序列但存在训练数据残留偏置；RL模型生成的独特序列较少，反映了在保持可行性与探索新颖性之间的权衡。

**2. 突变景观分析**

突变景观显示：
- 微调模型紧密复现了阳性训练集的"可行性标记"：可行序列优先避免567-576区域的突变，该突变与衣壳结构完整性相关
- RL引导的模型不仅保留这一可行性标记，还在允许区域外表现出更高强度的突变靶向，揭示该模型通过集中在相容区域突变主动驱动新颖序列变体的探索
- 预训练模型的突变景观缺乏结构化模式，突变广泛分布在整个目标区域，导致所有序列被分类为不可行

**3. 序列新颖性评估**

t-SNE可视化显示：
- 预训练序列占据与训练集和微调序列不同的空间区域，但新颖性仅为平均水平
- 训练序列、微调生成序列和RL生成序列在序列空间中形成梯度模式：右上区域富集训练序列，中央区域混合微调和RL序列，最左侧区域由RL序列主导
- 这种梯度对应新颖性增加，最左侧RL序列达到最高新颖性值，同时保持高预测可行性

RL生成序列在保持功能合理性的同时，成功超越了微调序列和训练集的最高新颖性值。

**4. 生物物理属性分布**

- **极性**：阳性序列比阴性序列显示略高的极性，微调序列和RL序列进一步将分布向增加的极性偏移
- **电荷**：阴性序列倾向于中性，非微调序列向正值偏移；阳性、微调和RL序列略微偏向阴离子性，表明该区域过度的正电荷是有害的

**5. 候选序列示例**

通过25区域网格采样选择的24个候选序列展示了多样化的新颖性分数（2.44×10⁻⁵至6.85×10⁻⁵），覆盖了广泛的极性和电荷组合。参考序列为：
```
DEEEIRTTNPVATEQYGSVSTNLQRGNR
```

候选序列在保持保守基序（如DE开头、RTTNPVA中间片段）的同时，在后半部分展示了高度多样化。

## 讨论与意义

**1. 通用PLM的局限性**

研究结果突出显示，通用PLM本身不足以形成功能性序列。预训练ProGen生成的10万个序列全部被分类为不可行，因为缺乏任务特定的适应。这一局限性不仅适用于AAV衣壳，也普遍适用于蛋白质工程，因为大多数序列空间是非功能性的。因此，从功能偏置的先验开始对于成功的RL引导序列生成至关重要。

**2. 微调与RL的互补作用**

- **微调**：有效恢复关键功能约束，复现可行性标记，但存在向训练数据的残留偏置
- **强化学习**：主动将突变集中在耐受区域同时避免有害位置，驱动功能探索超越训练集的最高多样性，有助于发现具有改变稳定性、抗原性或组织趋向性的变体

**3. 新颖性度量的解释**

研究使用ESM2嵌入的余弦距离作为新颖性度量。由于这些嵌入编码了丰富的蛋白质序列、结构和进化关系信息，该空间中的距离提供了从已知衣壳序列发散的生物学知情度量。这是探索训练数据中代表性不足序列空间区域的良好代理。

**4. 候选选择的挑战与策略**

由于RL奖励惩罚不可行序列，模型主要产生被预测为可行的序列，限制了预测可行性作为区分过滤器的效用。此外，可行性分类器在与模型微调相同的实验数据上训练，对高度发散的新颖序列容易产生假阴性。

研究提出的基于极性和电荷的网格采样策略利用蛋白质可开发性的既定原则：中等极性和电荷值通常与正确折叠、溶解度和功能维持相关，而极端值更可能损害这些特性。这种方法提供了一个与训练期间使用标准正交的探索轴，以受控和可解释的方式扩大搜索空间。

**5. 方法普适性**

虽然本研究以AAV2衣壳为案例，但所建立的工作流程——结合生成PLM、强化学习和基于生物物理学的选择——可推广到其他蛋白质工程研究。该框架提供了导航巨大蛋白质序列空间的系统方法，同时保持严格的功能约束。

## 精炼总结

- **三阶段渐进优化**：预训练模型（100%不可行）→ 监督微调（91-98%可行但有偏置）→ 强化学习（99-100%可行且高新颖性），展示了任务特定适应的必要性

- **双分支RL奖励结构**：多样性分支（ESM2嵌入余弦距离）与功能分支（ProtBERT可行性分类）相结合，实现功能约束与序列新颖性的平衡

- **可行性标记的保留与扩展**：RL模型不仅保留关键结构区域（567-576位点）的突变避免模式，还在兼容区域实现更高强度的突变靶向，突破训练集多样性极限

- **生物物理引导的候选选择**：基于极性和电荷的网格采样策略提供了与训练标准正交的筛选维度，确保候选序列具备良好的可开发性（developability）特征

- **AAV生物工程的开创性应用**：首次将PLM生成模型与RL优化相结合应用于AAV衣壳设计，生成序列在保持预测可行性的同时达到超越训练集的新颖性水平
